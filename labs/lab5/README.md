# Лабораторная работа №5  
## Основы интеграции LLM

В рамках лабораторной работы была изучена архитектура
интеграции языковых моделей в веб-приложения.

Реализован демонстрационный веб-интерфейс (HTML + JavaScript),
который имитирует процесс взаимодействия с LLM.

В реальной конфигурации приложение отправляет HTTP POST запрос
в формате JSON к API локальной языковой модели (Ollama),
после чего полученный ответ отображается пользователю.

Данный вариант позволяет продемонстрировать полный цикл
интеграции LLM без установки серверной части.
