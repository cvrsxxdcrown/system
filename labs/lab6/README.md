# Lab6 — Интеграция с веб-приложениями (MVC)

В рамках лабораторной работы реализовано веб-приложение на **Flask** с архитектурой **Model–View–Controller (MVC)**.

## Структура проекта
- `app.py` — **Controller**: обрабатывает HTTP-запросы и возвращает страницу (View)
- `model.py` — **Model**: сервис LLM (в этой версии — mock-реализация)
- `templates/index.html` — **View**: HTML-шаблон для отображения интерфейса и ответа
- `static/style.css` — стили (необязательно, но удобно)

## Как запустить (если установлен Python)
1) Установить зависимости:
   - `python -m pip install -r requirements.txt`
2) Запустить приложение:
   - `python app.py`
3) Открыть в браузере:
   - http://127.0.0.1:5000/

## Примечание
В данной версии используется демонстрационный (mock) LLM-сервис, который имитирует ответ языковой модели.
Это позволяет показать архитектуру MVC и принцип интеграции LLM как отдельного сервиса.
Реальный вызов API (например, Ollama) можно добавить, не меняя структуру приложения.
